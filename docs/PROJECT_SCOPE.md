# Project ATOM 项目范围

## 1. 项目目标

Project ATOM 将设计、集成并通过实验验证一套移动操作系统。在受控实验室环境中，系统需要使用已到货的 UFactory xArm 850，把试管从工位 A 运输至工位 B，并操作目标仪器。

项目的主要贡献是**系统集成和可靠任务执行**，不是构建通用自主化学实验室。系统包括移动底盘、商用机械臂、继承夹爪、感知与定位、运动规划、任务控制以及系统级安全架构。

本文记录 2026-08-21 与化学团队会议后形成的暂定范围，于 2026-08-29 更新机械臂型号，并于 2026-09-11 依据团队转述的导师意见细化人机共处与感知范围。仪器、硬件接口、尺寸、风险和验收阈值仍需通过实物测量和后续确认。

## 2. 目标演示流程

在限定实验室布局中，机器人以受监督方式执行：

1. 从已知安全状态启动；
2. 移动至工位 A；
3. 相对工位 A 定位或对接；
4. 获取试管夹取位姿；
5. 夹取试管并验证是否夹稳；
6. 把机械臂收回安全运输姿态；
7. 移动至工位 B；
8. 相对目标仪器重新定位；
9. 打开仪器盖子；
10. 把试管放入或插入指定位置；
11. 关闭仪器盖子；
12. 按下启动按钮；
13. 在存在可观察反馈时验证动作是否成功；
14. 返回安全状态，或在失败时报告可恢复故障。

第一版演示应使用无危险替代样品。危险、活泼、传染性、带压或对温度敏感的材料不在基线范围内，除非另行完成风险评估和审批。

## 3. 范围内工作

### 3.1 机械、电气和软件集成

- 模块化集成移动底盘、机械臂和继承夹爪；
- 检查负载、重心、可达性、稳定性和走线；
- 定义供电、通信和机载计算接口；
- 分别维护底盘、厂商机械臂和夹爪描述；
- 建立一致的 TF 树，并实测安装变换和 TCP；
- 在软件版本确认并记录后，建立导航、操作、夹爪和安全子系统之间的 ROS 2 接口；
- 使用带条件、超时和故障状态的显式任务状态机。

### 3.2 导航和工位定位

- 在已建图、受控区域内往返两个指定工位；
- 在传感器和运行边界内实现障碍物检测与避碰；
- 实现可重复的工位接近、对接或局部重定位；
- 在精密操作前补偿底盘残余定位误差；
- 定义机械臂运输姿态，并阻止底盘在机械臂姿态不安全时移动。

### 3.3 操作技能

- 试管夹取、夹持验证、运输和放置/插入；
- 操作一个指定仪器的一种盖子；
- 按下一个指定启动按钮；
- 机械臂碰撞检查和运动规划；
- 对接触型任务使用低速、受约束的末端运动；
- 对试管缺失、空夹、定位失败、运动受阻、插入失败、盖子失败和按键失败进行安全中止或恢复。

试管处理、开关盖和按键必须作为独立技能分别测试。每项技能都有自己的工装、感知假设、力/行程限制和验收标准。

### 3.4 感知和标定

- 标定底盘、机械臂、夹爪、相机和工位坐标系；
- 优先使用确定性的工位标志物或已知几何作为初始基线；
- 只实现目标任务所需精度的物体和插入口位姿估计；
- 在技术可行时验证夹取、释放、盖子状态和按钮触发；
- 测量定位、TCP 和放置不确定度，不能只使用名义坐标。

### 3.5 人机共享空间安全

- 针对实验员和机器人共享空间建立 hazard analysis 和运行边界；
- 定义设置/手动、自动测试、暂停/保护停止和故障恢复等模式；
- 为不同模式设置速度和工作空间限制；
- 按明确策略使用人员/障碍物检测触发减速、停止或禁止运动；
- 设置碰撞模型、禁入区域和仪器保护区域；
- 在硬件支持范围内集成保护停止和硬件急停；
- 安全事件后，在状态验证前禁止自动恢复运动；
- 记录命令、状态转换、故障和安全事件；
- 在共享空间测试前，先通过围栏或隔离区完成低风险验证。

避障只是安全架构的一层。软件停止不等于硬件急停；没有证据和正式验证时，项目不得声称满足安全认证或协作机器人合规要求。

## 4. 基线范围之外

- 自主提出科学假设或优化化学实验；
- 操作任意实验室仪器、任意盖子或任意按钮；
- 任意实验器皿和完全非结构化抓取；
- 在整个实验室内不受限制地导航；
- 在危险化学品附近无人监督运行；
- 高通量或全天候生产运行；
- 修改商用机械臂内部低层伺服控制；
- 把端到端学习控制器作为系统基础；
- 正式机械、功能安全或协作机器人认证；
- 化学结果解释、仪器数据分析和 LIMS 集成；
- 多台移动机器人协同。

只有确定性基线达到验收标准后，才能把其中部分内容作为 stretch goal。

## 5. 分阶段交付

### Stage 0：需求和风险定义

- 确认并测量试管、试管架、仪器、盖子、按钮和工位；
- 与化学团队一起观察并记录人工操作流程；
- 测量接触力、行程、间隙和易损区域；
- 定义人员活动范围、机器人运行区域和紧急响应；
- 在实施前约定可测量的验收指标。

### Stage 1：固定底座操作基线

- 在受控条件下分别调试 xArm 850 和继承夹爪；
- 复现并量化夹爪开合、夹取和释放；
- 建立模块化描述、TF、TCP 和碰撞模型；
- 在已知位姿下完成试管夹取与放置；
- 实现任务状态机、超时、故障处理和基本安全功能。

### Stage 2：仪器交互

- 相对目标仪器定位；
- 分别验证开盖、插入、关盖和按键；
- 先在固定底座上组合这些技能，再引入移动底盘误差。

### Stage 3：移动底盘集成

- 集成机械、电气、网络、TF 和安全接口；
- 验证机械臂处于运输姿态时的安全移动；
- 测量两个工位的到达和对接重复性；
- 用局部感知或对接基准补偿底盘误差。

### Stage 4 / Phase 4：端到端受监督演示

- 使用替代样品完成 A 到 B 全流程；
- 测试正常流程和预先定义的可恢复故障；
- 加入有代表性的静态障碍物；
- 只有风险控制和停止行为通过低风险测试后，才进行人机共享空间试验。

#### Phase 4a：进入检测与停止（先完成）

- 对机械臂工作体积及停止缓冲区检测人员、手和活动物体，未知占用也触发停止；进入后静止不能自动解除停止。
- 验证传感失效、遮挡、TF/数据过期和停止确认超时的禁止运动行为。
- 锁存停止、保持夹持并验证恢复条件；软件停止与硬件保护链分别验证。
- 先用隔离区内可控替代物测量完整停止延迟、制动扫掠和最小间距，再开展受监督人员试验。

#### Phase 4b：受约束动态绕行（依赖 4a 验收）

- 先比较停止后重规划，再实现外层反应区内的在线轨迹更新；内层停止条件始终优先。
- 右侧有人时，只有左侧整臂、夹爪及试管的路径可行才绕行；无路、超时或感知失效则停止等待。
- 绕行先限定在底盘驻停、试管已提起的自由空间搬运；插入、接触开盖与按键时禁止直接横移。
- 保持试管姿态及速度/加速度约束，记录规划截止期、间距、任务成功和失败恢复。

感知与停止链路从固定平台阶段开始开发。相机比较、标定到 waypoint 的变换链、参考文献与试验方案见 [roadmap 更新说明](technical_roadmap/README.md)。这里的 Phase 4 与技术工作包 P4（感知）不是同一编号。

## 6. 验收框架

最终数值门槛要在实物测量后确定。至少应报告：

| 项目 | 必须提供的证据 |
| --- | --- |
| 端到端任务 | 完整成功次数/尝试次数，以及每次失败的原因 |
| 试管处理 | 在说明试管质量、填充和表面条件后报告夹取、保持、释放和损伤结果 |
| 导航 | 到达 A、B 两点的位姿误差和重复性 |
| 局部对准 | 工位或插入口位姿误差及不确定度 |
| 操作技能 | 分别报告夹取、开盖、插入、关盖和按键成功率 |
| 时间 | 各阶段耗时和完整循环时间 |
| 安全响应 | 在说明速度、负载、传感覆盖和测试几何后报告检测至减速/停止的响应 |
| 故障处理 | 每种注入故障的结果，以及系统是否到达指定安全状态 |
| 仿真到实机 | 在 `docs/SIM2REAL_LOG.md` 记录所有关键差异 |

定量结论必须包含单位、测试条件、样本数和不确定度或离散程度。单次成功演示不能证明系统可靠。

## 7. 论文对范围的启示

`paper/paper/` 中的论文支持以下设计判断，但不能证明 ATOM 已实现相应功能。

| 论文 | 对 ATOM 的主要启示 |
| --- | --- |
| Yoshikawa 等，*Chemistry Lab Automation via Constrained Task and Motion Planning*（2023） | 多步骤化学任务需要显式任务与运动结构；碰撞和物料运输约束应进入规划；抓取前应局部重新观测。 |
| Sulaiman 等，*Kinematic Analysis and Integration of Vision Algorithms for a Mobile Manipulator Employed Inside a Self-Driving Laboratory*（2025，预印本） | 可达性、机械安装和视觉布置是耦合问题；人机共存应从系统设计阶段考虑。 |
| Burger 等，*A mobile robotic chemist*（2020） | 移动机器人可以连接面向人的现有仪器，但依赖结构化环境、设备改造和明确流程。 |
| Dai 等，*Autonomous mobile robots for exploratory synthetic chemistry*（2024） | 多仪器自主化需要大量固定自动化基础设施；可作为长期架构参考，不应作为本项目基线交付目标。 |
| Angelopoulos 等，*High-Accuracy Injection Using a Mobile Manipulation Robot for Chemistry Lab Automation*（2023） | 其毫米级任务中，单独依靠 AprilTag 粗对准不足；设备端相机和视觉伺服可以补偿抓取和底盘误差。 |

综合来看，推荐的层级是：**移动导航 → 工位相对定位 → 碰撞感知规划 → 任务专用末端精对准/接触控制 → 动作验证 → 故障与安全监督**。

## 8. 冻结范围前必须确认

- 已到货 xArm 850 的控制器、固件、标定文件、负载配置和安全接口；
- 移动底盘结构、稳定性、供电、定位和团队接口；
- 试管、试管架、仪器、盖子和按钮的实物参数；
- 插入、开盖和按键所需精度、力、行程及允许接触区域；
- 相机位置、照明、遮挡和是否允许增加标志物/夹具；
- 实验室布局、人员活动方式、限制区域和安全审批要求；
- 每项技能和完整流程的样本数与数值验收门槛。

## 9. 一句话范围说明

> Project ATOM 将把移动底盘、商用机械臂和继承夹爪集成为模块化机器人系统，在受控且有人共享的实验室环境中，以受监督方式完成试管从指定源工位到目标仪器的运输、开盖、插入、关盖和启动操作，并通过可重复实验验证感知、定位、导航、碰撞规避、任务控制、故障处理和分层安全架构。通用实验室自主化、危险环境无人运行和正式安全认证不属于基线范围。
