# UF850 腕部供电与相机通信研究

研究日期：2026-10-07。状态：资料核对与候选设计，未接线、未选购物料、未进行物理测试。

## 结论与型号边界

用户口述“xArm 858”“D345i”。项目 D-006 已记录 UF850 到货，既有相机记录仅为暂定 D435；本研究按 UF850 与候选 D435i 分析，不能据此确认相机实物型号或机械臂接口修订版。

UF850 官方将腕部网络接口定义为从腕部直通底座用户 RJ45 的物理以太网线，不是相机可直接接入的 EtherCAT 从站接口。D435i 是 USB-C / USB 3.1 Gen 1 相机，没有原生 EtherCAT 或 Ethernet 接口。

建议首先使用工具电源针脚的 24V，经两个独立 DC/DC 降压支路供逻辑和舵机；相机通过独立 USB 3 线连接主机并由 USB 供电。该建议尚不是已确认实施选择。

## 1. 供电设计

官方 UF850 V2.3.0 手册印刷页 35–36 与在线电气接口说明一致：12 针 Tool IO 的针 1/2 为 +24V，针 3/4 为 GND，电源电压范围 20–30V，最大电流 1.8A。不能解释为每个正电源针各有 1.8A；按工具接口总预算保守处理，实际接线按交付版本和线束定义核对。线色不能替代针位/极性核验。

TO0/TO1 是 NPN 开集电极输出，最大灌电流 100mA，激活时拉到地，不能当作可编程 5V 电源。RS485 A/B、数字输入和模拟输入也不是电源输出。

```text
UF850 Tool IO 的 +24V / 电源 GND
       │
       ├─支路保护─DC/DC 24→5.0V ─┬─ ESP32 开发板 VIN（核对具体板型）
       │                         └─ URT-1 逻辑 5V
       │
       └─支路保护─DC/DC 24→7.4V ─── URT-1 对应舵机电源端 → STS3215

非隔离方案：ESP32、URT-1、两路 DC/DC 与电源 GND 共地。
电机大电流回路直接回分配点，不经 ESP32 的细地线或 PCB。
```

URT-1 厂商 2017-10-08 使用说明第 1 页规定逻辑 5V 来自 USB，未接 USB 时需外供 5V；不能假定 7.4V 舵机输入会自动生成逻辑 5V。URT-1 是信号转换器，舵机动力经其相应供电端分配。其 UART 电平开关应与 ESP32 的 3.3V 信号兼容，逻辑供电仍为 5V。旧手册不证明当前板子所有修订版一致。

7.4V 支路以实际舵机铭牌/额定电压版本为前提，现有记录确认 STS3215 通信及约 7.5V 台架供电，不等于核实了额定电压变体或峰值电流。DC/DC 的持续、峰值电流和热降额需覆盖实际运动、夹紧、保持负载和异常限制；不能只按空载电流购买。

选型条件：输入覆盖 20–30V 并有适当瞬态余量、输出可准确设定、有短路/过流与热保护、可承受预期浪涌；舵机支路另评估回馈能量导致的过压、去耦、线径和连接器容量。不要把裸有刷电机的续流二极管直接并到智能舵机数据线或误接其供电；保护方式应匹配完整驱动系统。USB 与外部 5V 同时连接时，必须先核对 ESP32/URT-1 的电源隔离路径，避免反向供电。

预算公式（含各支路损耗）：

`I_24 = (5×I_5/η_5 + 7.4×I_motor/η_motor + P_other_input)/V_input`

示例仅为计算，不是实测或选型额定值：假设逻辑支路 5V/1A、舵机 7.4V/3A、两路效率均 90%、无相机/其他负载，输入在 24V 时约 1.26A，在 20V 时约 1.51A。浪涌、热降额、回馈及裕量尚未计入。若相机、USB 延长器或腕部电脑也从 Tool IO 取电，必须重新计入；USB 延长器可显著增加负载。

## 2. 臂内网口存在资料版本差异

| 来源 | 网络接口描述 | 工程含义 |
| --- | --- | --- |
| 官方 UF850 V2.3.0，印刷 p27；本地 PDF 的文字抽取 | M8 4-pole、内部 100M Ethernet、CAT5 | 不能假定有四对线或千兆能力 |
| 当前在线手册 §4.5 | 正文 M8 4-pole、1000M、CAT5E；下方却为 8-pin/four-pair 定义 | 网页自身也有不一致，不能直接选配接头 |

确认顺序：机械臂型号/序列号/交付版手册 → 腕部针数与配套转接线 → 底座 User Ethernet 路径 → 厂商确认线对/屏蔽/额定用途 → 普通 Ethernet 的协商速率与实测吞吐。普通 Ethernet 测试通过也不证明专有 USB-over-CAT 信号链通过。这里没有实物针位测量。

## 3. 相机可行路线

| 路线 | 连接方式 | 优点与限制 |
| --- | --- | --- |
| A，建议先验证 | D435i → USB 3 → 主机；ESP32 → 独立 USB 串口 → 主机 | 保留原生相机接口与当前夹爪通信。需验证活动线束弯曲半径、应力释放、全工作空间余量和稳定性；相机通常由主机 USB 供电 |
| B，标准网络 | D435i → 短 USB 3 → 腕部采集电脑 → 臂内 Ethernet → 主机 | 电脑完成 USB 采集，发送 RGB/深度或本地计算的结果；增加质量、热源、功耗、软件与时间同步问题。ESP32 不能充当该 USB 3 RGB-D 采集电脑。旧 rs-server 教程有 SDK 版本限制，不直接采用旧示例 |
| C，专有延长链路 | 主机 USB → 延长器 LEX → 臂内铜线 → REX → 相机 | 要一对主动 USB 3 延长器；普通 USB 转 RJ45 网卡/无源转换头无法转换相机。必须验证线对、线缆规格、转接头、屏蔽、USB 传输类型和 D435i 兼容性；4 针/两对线版本不能默认支持要求完整 CAT5e 的设备 |
| D，更换相机 | 原生 Ethernet RGB-D 相机 → 臂内网络 → 主机 | 可研究，但改变已有相机、安装与标定；仍需核对吞吐和供电，不作为本次默认选择 |

USB-over-CAT 的 RJ45 LINK 可能是专有点对点接口，不能因接头形状相同而接入普通交换机或当成 EtherCAT。Icron Raven 3301 官方文档给出 CAT5e、5Gbps USB 延长方案，远端电源适配器为 5V/4A；这是产品输入配置，不代表相机实际消耗 20W，也不证明该产品兼容本机械臂内部线束。这里只用于证明主动延长技术存在，未推荐购买。

网络带宽计算示例：未压缩深度 Z16 + RGB8，各 640×480、30fps，共 `640×480×30×(2+3)×8 = 368.64Mbps`，未含协议开销。两者各 1280×720、30fps 为 1105.92Mbps。它们是理想数据量计算，不是相机实测支持的同步流组合或实际吞吐。100Mbps 无法承载上述原始流；1Gbps 也无法承载后一组合。可降低帧率/分辨率、只传必要 ROI/结果或评估合适压缩；有损深度压缩会影响定量深度，必须验收，不能直接照搬 RGB 视频压缩。

## 4. 夹爪信息传输

5V/7.4V 分配只解决供电。现有链路应保持主机 USB 串口 → ESP32 → UART → URT-1 → 舵机，ESP32 同时采集传感器。相机另走 USB 3。

若希望夹爪也无外置 USB 线，可研究 Tool RS485 → 兼容 3.3V 的 RS485 收发器 → ESP32。它需要新增板级接口与固件协议适配，RS485 A/B 不能直连 ESP32 UART，也不能把 URT-1 的 SMS RS485 舵机端当作任意主机协议网关。采用机器人 SDK 转发前需验证请求/响应、延时、故障、超时及现有心跳的可行性。一个主机入口应保持单一命令所有权。Wi-Fi 也需延迟/丢包和故障测试，不能因为 ESP32 支持无线便替代已验证链路。

## 5. 下一步所需证据

1. 相机铭牌或 RealSense Viewer 枚举型号；机械臂铭牌、腕部网口针数和配套线束型号。
2. URT-1 实物版本、ESP32 开发板供电原理图、STS3215 额定电压与峰值电流规格。
3. 断开负载时核对 Tool 电源针位、极性和电压；台架单独调好降压输出，再接逻辑、再接舵机。
4. 用限流供电和可观测保护测试启动/运动/受控夹紧与保持负载；记录最小输入电压、逻辑和电机输出压降、峰值电流、温升、ESP32 复位、传感器噪声和串口错误。不建议以无保护堵转作为初次测试。
5. USB 3 直连验证 RGB/深度/IMU 实际配置，再验证所需运动范围的线束与重复性。如果研究内置网络，独立验收协商速率、吞吐、帧丢失、延迟和重连。

测量应记录仪器、负载、运动参数、持续时间、样本数和不确定度。本研究没有上述实测，不能宣称整套接口已稳定或已通过安全验证；软件停机不等于硬件急停，失电可能造成夹持变化/掉落。
