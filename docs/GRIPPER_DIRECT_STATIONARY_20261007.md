# 2026-10-07 Agent直接连接后的静止测量

用户停止自己的motor_console，明确授权Agent自行连接测量。lsof未显示
/dev/cu.usbserial-0001被占用。初次沙箱访问被拒绝，没有打开串口；
获授权后使用现有GripperController，enable_motion=False，正常控制线策略，
不请求复位。使用临时Python环境的pyserial3.5，未修改用户Python环境。

程序发送STREAM ON、PING及KEEPALIVE，没有ARM、MOVE、JOG、OPEN/CLOSE、
ZERO、RESET、DISARM命令。关闭采用已有控制器策略；本次armed=false，
因此没有退出STOP请求。采集完成后串口已关闭，未保持后台控制进程。

## 条件与连接状态

启动同步期间收到重复旧片段/启动文本，以及一个完整
`# ATOM_MAG_V1 units=uT; motor_boot_disarmed`。虽未请求复位，不能把此
新会话假设成与此前会话状态完全连续。具体USB/驱动/启动机制未确定。
同步完成、传感器/电机反馈新鲜且moving=false后才开始统计窗口。

初始状态：固件armed=false、moving=false、无fault，位置2411counts，
load_raw0、电压76raw、温度24raw、地址20(0x14)、continuous_position=true。
采集末状态位置2410counts，其他上述状态相同。固件armed状态不等于
独立测量舵机扭矩使能位/电流；此实验没有改变使能状态。
沿用用户报告的空载条件，当前准确机械臂姿态、金属距离、温度°C及
实际电源电压V没有独立测量。不能把本次当成仅改变姿态的受控对比。
主机状态快照观察范围：位置2410–2412counts、load_raw0–20、
voltage_raw76–77、temperature_raw24–25，全程固件armed=false、moving=false、
fault为空。以上是寄存器反馈，不是物理位移、电压V或接触力测量。

差值到N的换算、无载闭合影响、接触/持有和力控制均没有在此轮验证。
