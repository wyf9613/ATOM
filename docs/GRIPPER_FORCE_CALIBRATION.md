# 固定物体夹持与标准力标定

日期：2026-10-07。力标定流程仍在准备；已采到实物空载磁场，尚无标准力数据。

更新：已采集多个姿态的实物空载磁场，见
[静止基线记录](GRIPPER_STATIONARY_BASELINE_20261007.md)。尚无标准力加载数据。

## 用户指定方向：闭合前基线与差值法

2026-10-07 用户要求不使用跨姿态固定磁场零值，而在每次夹爪闭合前
以当前空载读数作为零接触力参考，以当前读数减去该基线的差值作为
后续力估计输入。用户已明确更正为差值法；不指定插值算法。按此方向准备标定，
不把绝对磁场等于0当作零力条件。此方法尚未实现或验证，force请求继续阻断。

流程建议：机械臂停稳、保持当前开口并确认没有接触载荷，先记录一段
有效磁场样本，其均值作为本次B0（初始试验可用约2s，窗口和稳定判据须
由实测确认）。保存基线时间、姿态、开口、温度及波动；漂移或无效数据
未通过判据则不进入力控制。开始加载后冻结这个基线，不能自动重新ZERO
或连续扣除加载中的读数，否则会把真实接触变化消掉。

先在代表性姿态/开口做空载闭合实验，检查夹爪运动、磁体/传感器几何和
舵机状态本身是否产生ΔB。若有，单纯B−B0不能当作受力信号；需要
按位置建立空载变化补偿，或在已验证的窄开口范围使用局部标定。
多姿态加载实验还需验证ΔB→N的灵敏度/曲线是否相同；仅扣零不能自动
补偿灵敏度变化。当前多姿态静止实验只能检查背景值和漂移。

已完成一轮[空载小步闭合实验](GRIPPER_EMPTY_CLOSURE_20261007.md)：名义闭合
60counts后ΔXYZ约[−2.019,−0.435,−6.077]µT，回起点后约
[+0.078,−0.442,−3.802]µT。位置与时间因素尚未分离，不能直接把ΔB全归为
接触力，亦未根据这一轮生成补偿曲线或换算系数。

差值定义：

```text
ΔBx(t) = Bx(t) − Bx0
ΔBy(t) = By(t) − By0
ΔBz(t) = Bz(t) − Bz0
```

ΔB单位µT，不是N。用独立测力参考采集(ΔBx,ΔBy,ΔBz,位置,F_normal_N)，
确定差值到接触力的换算关系；目前不选定单轴、向量模长、线性系数或
其他拟合算法。不能直接把某轴差值当作力，也不能凭静止基线猜换算系数。
必须用独立轮次验证误差/不确定度，并设量程与装配/位置适用范围。
超标定范围返回unknown并阻断，不外推、不把极端值钳到最大力伪装正常。
本方案替代跨姿态固定B0的设想，不替代标准测力、故障门槛或ESP32本地
力闭环的验收。台架位移与加载实验须人工监督，不能先开放未标定力命令。

## 先固定实验定义

记录物体 ID、尺寸/mm、实测质量/g、重心/姿态、夹持位置、接触材料、
垫片及磁体/传感器装配版本、润滑条件、温度/°C、电源/V、固件版本、
串口、编码器位置/counts 和实际开口/mm。

力定义采用传感器所在单指、沿接触法向的力 `F_normal_N`；记录该方向
对应的传感器轴和正负号。不可自动把它乘二称为总夹持力。物体重量
作用方向与夹爪法向通常不同；质量×重力得到重量，不能直接当法向力。

选定测力计/称重单元，记录型号、校准日期、量程、分辨率、测量不确定度
和安装方向。若用电子秤，必须使夹指载荷经夹具沿秤的标定轴传递，
记录去皮、偏心误差及实际重力换算；不能用物体自重代替夹指接触力。

## A：固定物体持有验收

1. 将夹爪固定在台架，物体下方放接物托盘；本阶段不让机械臂自动搬运。
   确认当前机械行程与物体尺寸，保留原故障/看门狗门槛。
2. 空载确认磁场有效、反馈新鲜、无故障，并记录未接触基线。
   串口只能由现有 GUI/controller 或 console 其中之一占用。
3. 人工监督，先用保守的位置小步接近接触。`Close=2000` 是位置端点，
   不能把它作为任意物体的自动夹持目标；触发故障先停止检查。
4. 在确定不压坏物体且没有超限后，记录持有位置与参考力（有仪器时）。
   给物体加可观察的标记，测试前后测量相对位移。
5. 初始验收条件建议为同一物体/同一姿态持有 60 s、独立重新抓取 10 次；
   记录每次实际时长、位移分辨率、滑移/mm、掉落次数与接触损伤。
   这些是拟定测试条件，不是已验证指标。先设定可接受滑移阈值，结果中
   明确“在某测量分辨率下未检测到滑移”，不能承诺任意工况不会掉。
6. 在托盘保护下单独测试页面退出/控制进程失联后的保持，记录停止确认、
   持有状态与时间。断电保持是另一实验；舵机扭矩保持不能证明断电不掉。
   如需这一能力，须验证机械自锁/锁扣/被动保持方案。

若测试中只有位置和磁场，保存为“固定物体持有位置配方”，不保存
`target_force_n`。换物体、接触材料、装配、姿态或加速度后重新验收。

## B：力标定采集

1. 使用固定台架和标准测力参考，通过受控外部加载或人工监督的位置
   微调加载。不要启用尚未标定的自动力闭环。
2. 每次新装配先采至少 30 s 无接触基线，记录 Bx/By/Bz、温度和零偏漂移。
   不在带载状态 ZERO。传感器约 10 Hz 是历史观测，记录本次实际采样率。
3. 在与物体匹配的至少 3 个开口位置，设置零载及至少 5 个非零参考力等级；
   最大力由物体/夹具/参考仪器的能力确定，不把历史“5 N”要求当作安全上限。
   不确定时先做低载荷试验确定可用范围。
4. 每位置至少 3 轮加载→卸载，每级稳定后采至少 10 s；同步记录参考力
   与磁场和编码器，并保留稳定前的原始数据。记录稳定判据、真实样本数、
   加载方向和时间。持续波动的载荷须同步采参考力，不能贴一个恒定标签。
5. 拆装后再独立采集验证轮次；至少保留整轮/整次装配作验证集。
   不能随机拆分同一个 10 s 平台内高度相关的样本冒充独立验证。
6. 保存原始串口、仪器记录和配对 CSV。每平台记录均值/标准差/漂移、
   参考力的不确定度；样本标准差不能直接当作总测力不确定度。

优先从有物理意义的低阶模型开始：基线后的 ΔBx/ΔBy/ΔBz 与位置 →
单指法向力。比较单轴和多轴线性模型，确有证据才引入非线性项。
报告独立验证 MAE、最大绝对误差、加载/卸载迟滞、零偏漂移，以及按力级/
开口/装配分组的误差。只有参考仪器、配对误差、重复性与模型残差等均
被评估后，才能给出不确定度；未满足预定误差要求则保留未标定状态。

## C：调整目标力的解除条件

模型文件需含装配/传感器 ID、力定义与方向、磁场单位、系数、基线规则、
力/磁场/位置/温度有效范围、数据出处、验证误差与不确定度、版本和日期。
越量程、未知装配、数据失效或位置超范围必须返回 unknown 并阻断力命令。

目标力可调还需要 ESP32 本地有界闭环，包含接触检测、限速、过力处理、
传感器新鲜度、超时、故障锁定和保持策略；网页不能负责实时力闭环。
先在台架验证阶跃、不同目标力、加载扰动和故障，再开放 UI 的 N 输入。
每个目标力重复 A 的持有/释放验收，确定针对这个物体的最小可靠持有力
及不损伤的上限。校准成功不等于控制器已实现，也不等于机械臂运输验收。

## 记录模板

将每次实验保存在 `tmp/gripper_force/<session_id>/`，汇总证据进入
`docs/GRIPPER_VALIDATION_LOG.md`；未确认项进入 ASSUMPTIONS/KNOWN_ISSUES。

```csv
session_id,assembly_id,object_id,run_id,split,phase,host_time_utc,device_ms,position_counts,aperture_mm,bx_uT,by_uT,bz_uT,reference_force_N,reference_uncertainty_N,temperature_C,valid,notes
```

`phase` 用 baseline/loading/unloading/holding；`split` 用 fit/validation。
缺测留空，不能填 0。原始数据与参考仪器时间偏差必须保留。现有
`tools/gripper/capture.py` 只采磁场，不采标准力或编码器；GUI/console
控制期间不能再打开 capture 争用串口。串口或实际设备尚未确认前不启动采集。
