## 当前状态

- ESP32 USB端口在本Mac为/dev/cu.usbserial-0001，旧Windows曾为COM4；
  队友电脑必须重新列设备，不能直接沿用端口名。
- 接线沿用原方案：电脑USB→ESP32，VIN→URT-1逻辑5V，舵机独立供电；
  传感器3V3/GND/SDA21/SCL22，串口RX2=16、TX2=17，不在交接时重排线。
- 三个姿态会话空载背景不同；尚未分离姿态/环境金属/时间影响。
- 一轮空载闭合2410→2390→2370→2350→2410counts已完成，名义闭合60counts
  后ΔXYZ约[−2.019,−0.435,−6.077]µT，返回后[+0.078,−0.442,−3.802]µT。
  不能把整个差值直接当作接触力，也没有生成位置补偿系数。
- 最后STOP/DISARM确认，串口关闭。位置末读数2409counts；这是最后记录，
  下一次连接仍须重新读状态，不能视为实时状态。
- 方案是每次停稳且无接触时取B0，加载后冻结，计算ΔB=B−B0。
  差值单位µT；没有N换算、标准力数据、力闭环或物体持有验收。

## 下一批测试

所有以下项目是计划，尚未完成。保持现有限位、反馈/心跳门槛；首故障
终止、不自动复位续跑。复用已有controller/UI/ROS接口，不新增任务节点。

| 顺序 | 测试 | 条件与建议样本数 | 要解决的问题 / 交付 |

| T01 | 使能后固定开口的等时长对照 | 与上一轮相同姿态/开口，原位ARM，记录至少与整段闭合测试相当的时间，初始90s；分段统计 | 估计不运动时的漂移/短暂波动；保留温度raw、位置、负载、电压raw，未测量项留空 |
| T02 | 空载小步闭合/回程重复 | 复用2410附近的3×20counts局部步骤；各平台停稳2s、采10s，至少3轮，记录实际初始位置；配对T01 | 分离可重复的位置变化、时间趋势、回程残差；决定是否需要开口补偿，不能凭单轮拟合 |
| T03 | 固定开口A→B→A姿态对照 | 不改变开口/装配，记录实际关节角或姿态、停稳时长、金属距离；各停稳姿态3×30s，至少3轮 | 检查返回原姿态能否恢复，以及跨姿态差值法灵敏度验证的前提；若测金属影响，另固定姿态只改变金属位置 |
| T04 | 标准法向力加载/卸载 | 先确定仪器/力定义/可用量程；至少3开口、零载+至少5非零等级、每级稳定采10s、至少3轮；另留独立验证轮次/装配 | 标定ΔB与法向力N，报告迟滞、漂移、误差、不确定度和有效范围，验证越界拒绝；单指/总夹持力不能混用 |

| T06 | 固定物体持有/释放 | 记录物体质量、接触材料、姿态、夹持位置；建议60s×10次独立重新夹持，并测滑移/损伤 | 得到该物体的可复现持有条件；不能扩大为任意物体或断电不会掉 |
| T07 | 带托盘的失联/保持与联合停止 | 分别测试USB/页面/进程退出、传感器失效、实际停止确认；完成夹爪单独验收后再验证机械臂同步停止 | 记录真实时延/持有结果/人工恢复；软件STOP不等于硬件急停，断电保持另测 |

## 队友连接机械臂时与夹爪相关的交接

1. 先核对实际控制器/固件/IP和既有driver兼容性，保持夹爪独立台架流程；
   USB夹爪链路不需要移接到机械臂末端I/O。夹爪串口只能由一个工具占用。
2. 新工具模型入口是atom_xarm_description/urdf/uf850_atom.urdf.xacro，
   配套srdf/uf850_atom.srdf.xacro。现有arm-only/G1启动器未加载该组合；
   队友须核对MoveIt与TF发布者实际使用同一套模型。
3. 法兰+Z51.964mm和TCP仍是CAD值，实物安装朝向、TCP、payload/CoM、
   手指编码器→关节状态及相机/PCB/线缆/携物包络仍待测。当前SRDF手指被动，
   不能假设规划器自动知道实物夹爪开口。
4. 在实际关节反馈与测量后的模型下，验证工具碰撞能使已知冲突姿态被拒绝，
   再验证目标和整条路径。不能通过忽略夹爪/机械臂碰撞消除报错。
5. 当前联合硬件配方仍未验收，不将hardware_arm_integration_verified设true
   代替验证，不用仿真许可驱动实机。此交接没有替队友启动机械臂或发送命令。

模型边界见[法兰集成](GRIPPER_MOUNT_V2_INTEGRATION.md)，夹爪连接操作见
[当前流程](GRIPPER_CONNECTION_AND_TEST_WORKFLOW.md)。
