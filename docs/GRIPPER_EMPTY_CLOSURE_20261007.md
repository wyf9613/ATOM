# 2026-10-07 空载小步闭合与回程

用户明确授权Agent执行：当前位置使能，取10s基线，三次各20counts
名义闭合，停稳采10s，返回起点后再采10s。沿用用户报告的无物体状态，
请求机械臂/环境保持不动；准确姿态、开口mm、物理温度、电流与金属距离
未独立测量。本轮没有标准力参考或接触载荷。

## 执行与边界

单串口/单运动所有者，复用生产GripperController，临时脚本仅编排
已有DISARM、ARM、MOVE、STOP能力，不新增节点或控制实现。
初始反馈健康、位置2410counts、firmware configured/continuous_position=true；
目标2410→2390→2370→2350→2410均在现有2000–2600测试范围。
先显式DISARM得到确认，再原位ARM。每个平台采集前等待2s，并检查
无故障、新鲜传感器/电机数据、armed=true、moving=false及目标误差≤3counts。
等待时间和编码器判据不是实测物理停稳或位移精度保证。

没有ZERO、RESET、阈值/速度/行程修改、固件上传或机械臂命令。
既有负载、电压、温度、心跳和传感器门槛保留；首异常中止、不复位续跑、
不在故障后自动返回。原始运动和传感器记录均保留。
全部平台和返回完成，无fault；结束STOP和DISARM均回执成功，
最终armed=false、moving=false，串口已关闭。

## 对差值法的含义

这是一轮局部开口范围内的空载测试（N=1序列，3个闭合平台），不能当作
全行程或多姿态验收。没有物体接触时，磁场仍随本序列变化，故不能
把当前磁场减闭合前基线的全部差值直接换算成接触力。

X轴闭合3变化约−2.019µT，返回后差约+0.078µT，与位置相关影响相符，
但没有固定开口的同期时间对照，尚不能单独确定位置项。
Z轴闭合3变化约−6.077µT，返回后仍约−3.802µT；存在时间漂移、回差、
机械/磁体响应等未分离因素。不能用这一序列直接生成位置补偿系数，
也不能把返回偏移全称为漂移或全称为回差。

下一步建议先做同等时长、使能且固定开口的空载时间对照，再重复往返，
检查变化是否可复现。若位置影响确认，测得空载基线随开口的关系后补偿；
若仍有时间漂移，则另设停稳/基线质量门槛。最后才用独立测力装置标定
剩余差值到法向力N的关系。软件force请求继续阻断，未修改力模型。
