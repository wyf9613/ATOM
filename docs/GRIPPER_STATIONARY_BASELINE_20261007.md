## 基线与适用范围

保存的暂定空载磁场基线：

```text
B0 = [−280.215845, −205.273843, 7842.070449] µT
ΔB = B − B0
```

仅用于同姿态、同开口、同装配和相近环境下的离线相对变化分析。
未写入固件、未替换原ZERO基线、未启用力控制。磁场背景不需要接近零；
本次未有零磁场标准，也不是芯片本体零偏校准。
磁体相对传感器、开口、装配、温度/周围磁性物体或舵机电流变化后须重新
采空载基线或建立补偿模型。后续加载/卸载仍需独立测力参考才能得到N。
