# 夹爪相机支架概念方案

日期：2026-10-02。状态：当前版本为 [CAD v2](../../source_cad/camera_bracket/v2/README.md)：按用户要求改为双夹板四层连接、窄伸出臂，去除限位挡边和加强肋。原 CAD 两孔尺寸已提取，实物、相机孔位及强度验证未完成。下文保留最初概念建议作为历史记录，当前结构和尺寸以 v2 说明为准。

## 输入与证据

- 用户提供夹爪截图，指出上方竖直连接片上的两个孔；用户说明这两个孔通过现有螺栓/螺母固定左右壳体，建议复用并向夹爪前方延伸。
- 用户回复“应该是435”，因此仅按 D435 作初步接口参考，实物型号未确认，不能视为相机采购或型号选择。
- 项目存在原始 `hardware/end effector/End Effector Assembly V3.step` 和 `.f3z`。本次未修改原始文件，也未从截图推定孔距或尺寸；截图与原始模型/实物的一致性仍需检查。
- D435 官方产品规格列出底部 1/4-20 UNC 和两个 M3 安装孔：[官方产品页](https://www.realsenseai.com/cn/products/d435/)。1/4 英寸公称直径为 6.35 mm，20 牙/英寸对应螺距 1.27 mm；不是 3/4 英寸，也不能用 M6 替代。
- 机械尺寸、螺钉最大插入深度应以确认型号的官方机械图为准：[D400 系列数据表](https://realsenseai.com/wp-content/uploads/2025/09/Intel-RealSense-D400-Series-Datasheet-October-2025.pdf)。本次未核定插入深度，不能据此下单螺钉长度。

## 建议几何

采用独立的“后端两孔竖直固定板 + 向前延伸托板 + 前端相机安装台”，从图中的夹指伸出方向定义前方。

1. 后端固定板贴在现有竖直连接片可用的外侧，复制两个孔的实际轴线及孔距，先使用圆孔。复用原有壳体夹紧路径；不得把较厚支架插入左右壳体的配合面而改变壳体间距。
2. 通过必要的高度台阶越过现有连接片，延伸至壳体前沿附近。延伸段采用两条侧肋或槽形截面，降低弯曲与扭转。前沿坐标以 CAD/实物为准，不能从截图比例取得。
3. 前端安装台承托相机底部，开螺钉通孔；从托板下方将 1/4-20 UNC 螺钉旋入相机已有的内螺纹。支架本身无需再攻同规格内螺纹。通孔需给 6.35 mm 螺钉实际装配间隙。
4. 增加与相机非光学外壳接触的定位挡边/定位座，约束单颗底部螺钉周围的转动；避开镜头、发射器、USB 接头及散热区域。接触位置需按实物模型确认，不能夹压光学窗口。
5. 镜头朝夹爪工作区，实际高度/俯仰根据目标 Tag 与抓取点视线、夹指运动包络及工作距离确定。相机前面板可以接近壳体前沿，但底部螺孔位置必须按相机机械图反算。
6. 预留底部螺钉工具空间和 USB 应力释放固定点，避免线缆拉力改变相机姿态。

打印件可先用于装配/视线样机；壁厚、侧肋尺寸、材料和最终制造方式在悬臂长度、相机质量、机器人加速度、打印方向等输入确定后评估，不在本次概念中声称承载能力。

## 需要测量与核对

| 参数 | 用途 | 当前状态 |
|---|---|---|
| 相机完整型号和机械图 | 包络、质量、底部螺孔、允许插入深度、接口位置 | 用户暂记为 D435，未确认 |
| 两孔孔径、中心距、轴线方向 | 后端安装草图 | 未提取/未实测 |
| 原螺栓规格、长度、垫圈及螺母位置 | 共用连接并保持原壳体夹紧 | 未确认 |
| 固定片到前沿距离、可用高度、工具空间 | 延伸段及台阶尺寸 | 未确认 |
| 壳体材质与孔位局部结构 | 附加弯矩及夹紧可靠性 | 未确认 |
| 夹指全行程、目标视线、相机工作距离、线缆包络 | 排除遮挡及运动干涉 | 未验证 |

共用螺栓通常需要增加有效长度，但必须按增加的夹紧厚度、垫圈及实际螺母啮合重新选型。相机螺钉的伸入量按“螺钉头下长度 − 托板厚度 − 垫圈/间隔厚度”计算，并核对最大插入深度，避免顶底。

## 验证与后续模型

先完成装配、夹指全行程、视线及线缆检查，再评估支架在载荷下的位移和重复装拆后的姿态变化；结果需记录载荷/运动条件、单位、样本数和测量不确定度。

安装后测量相机与夹爪的固定变换，完成手眼标定。螺钉中心不是深度光学原点。支架及相机保持独立组件；后续机器人描述使用固定变换组合，不重新导出单体 arm-plus-gripper URDF。本方案不修改现有仿真相机安装参数，也不表示仿真安装已在实物上验证。
