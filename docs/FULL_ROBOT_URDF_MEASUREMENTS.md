## 测量基准

底盘停在水平地面，记录当前载荷、轮胎状态和所用量具。临时测量原点 O 取左右驱动轮轴心连线中点在地面的垂直投影；X 向车头，Y 向车左，Z 向上。这是采集尺寸的基准，后续需转换到核实过的厂商底盘 frame，不能直接假定它就是厂商 `base_link`。

每项填毫米或角度，并记录测量方法、读数次数 N、各次读数及估计误差。例如“卷尺读数误差约 ±… mm”；不要将量具分辨率直接当作安装精度。不便测轴心时可先使用车壳中心等可重复基准，但须说明该基准到 O 的关系。

## 优先测量：装配姿态与碰撞外形

| 项目 | 请提供的尺寸/信息 | 实测记录 |
|---|---|---|
| 型号与前向 | 机械臂铭牌完整型号；底盘车头方向；机械臂底座上的方向标记与车头的关系 | 待测 |
| 底盘核对 | 实物长、宽；地面到连接架实际接触的安装平面高度；是否有额外顶板 | 待测 |
| 机械臂底座中心位置 | 底座安装面中心相对 O 的 X、Y、Z；Z 必须量到机械臂底座接触的安装面，不是型材顶面或关节中心 | 待测 |
| 机械臂安装朝向 | 底座方向标记相对车头的角度；安装面是否水平，有倾斜则量前后/左右高度差及对应跨度 | 待测 |
| 铝型材规格和布局 | 每根截面外宽×外高（如实物确为 40×40 则填该值）、长度、数量、横/竖方向；各根中心线相对 O 的位置或足够还原这些位置的间距 | 待测 |
| 支架安装板 | 上下板各自长×宽×厚，板的位置、是否偏心；底座中心相对上板中心的偏移；板间高度 | 待测 |
| 其他外凸件 | 角码、控制盒、激光雷达、电脑、线缆束等的外包尺寸和位置；没有的项目注明无 | 待测 |

最先给出底座中心 X/Y/Z、底座朝向，以及支架的宽/深/高和截面规格，就能确定运动学安装关系并开始连接架碰撞建模。若连接架结构不规则，还需各根型材和板的位置。只给支架总高度不足以恢复装配。

可用俯视和侧视草图标注上述尺寸。已有装配照片可用于辨认结构与车头，但不能代替尺寸或标定。机械臂当前关节姿态不能单独确定底座坐标方向，应使用厂商定义的基准或底座标记。

## 后续完善

| 用途 | 后续数据 |
|---|---|
| 底盘轮组与运动学 | 官方版本的轮径、驱动轮中心距、驱动轮/脚轮位置和轴向，与实物核对；无需现在重复测量每个螺孔 |
| 安装板可制造 CAD | 孔距/孔径、孔组相对板边的位置、槽位、螺栓规格；整机简化 URDF 不依赖逐孔建模 |
| 末端安装与 TF | 新法兰、夹爪、D435i 是否已安装；实际法兰转角、安装厚度、TCP 和相机外参；现有 CAD 偏移不能作为标定结果 |
| 动力学 | 支架/安装板/末端各自称重，质心和惯量来源；型材不能按实心铝盒估算质量或惯量 |
| 整机运动规划 | 底盘外轮廓及外凸件、支架与机械臂/夹爪扫掠空间、线缆活动包络；规划碰撞和实物间隙需另行验证 |

首版可核验装配树与简化碰撞几何；动态仿真需另补可信惯性数据与底盘接口，不能由几何显示通过推断控制已可用。

## 模型整合与验收

- 底盘与机械臂分别引用厂商来源，自有支架、法兰 V2、ESP32 V1、相机支架 V3 和夹爪保持独立模块。对第三方依赖记录来源、版本及许可。
- 现有 `uf850_atom.urdf.xacro` 把机械臂固定到 `world`。整机组合时须改为挂接到连接架的 `arm_mount`，保留独立机械臂入口，并避免重复 root、link/joint 名和驱动接口。
- 测量数据统一转换为米与弧度。静态安装链计划为 `base_link → arm_mount → 厂商机械臂基座 → … → 工具/相机`；连接架可以有多个固定子 link。厂商基座原点是否落在底座安装面须核实。
- `map → odom → 底盘` 的动态 TF 由定位/里程计模块管理，不在可移动整机 URDF 中用固定 `world` 关节代替。相机光学 TF 以后按真实驱动和标定配置接入。
- 展开 Xacro 后检查单根连通树、名称唯一、mesh URI、关节轴向和限制、安装变换、完整碰撞外形；更新整机 SRDF 的机械臂组/夹爪组/移动底盘规划接口和必要接触排除。检查与测试结果另行记录。
