## 几何依据（单位 mm）

原 STEP 两个壳体组件都有对应圆柱孔：半径 1.6，中心 x = -33.7 / -18.7，z = 21.275，孔轴沿 Y。因此原 CAD 孔径 3.2、中心距 15；这些是模型尺寸，不是实物测量。闭合壳体该孔圆柱的外侧 y = 45.494，支架固定板从该外侧向外增加 4 mm，不插入两壳配合面。

支架复用孔暂开直径 3.4；厚度 4；托板下表面 z = 35.275；相机通孔直径 6.8，供 1/4-20 UNC 螺钉穿过。这些为设计初值，装配公差与强度未验证。

相机按 D435 的 90 × 25 × 25 外包络表示（宽度沿 Y，深度沿 X，高度沿 Z），前面朝 -X，与壳体前沿 x = -81.2 对齐。底部孔暂取包络中心，**不是已核定的厂家孔坐标**；需确认实际型号并按机械图更新孔位、挡边和插入深度。螺纹位于相机内部，支架上只建通孔，未模拟螺纹及紧固件。

## 已做检查与限制

- 支架为一个有效实体，STEP 导出再导入仍为一个有效实体。
- 与原 STEP 各组件在原始静态姿态的布尔相交体积未检出大于 0.001 mm³ 的干涉；相机占位块相交体积为 0。仅为几何检查，不表示测量精度或运动包络已验证。
- 未检查螺栓/螺母、垫圈、USB 插头、线缆和夹指全行程；未进行负载/振动、打印工艺、硬件匹配或手眼标定验证。
- 相机螺钉下方有壳体，建议先把相机装到独立支架，再安装支架；最终需核对工具路径和螺钉头空间。
- 原始 `hardware/` 文件未改动；STEP 受仓库现有 Git LFS 规则管理。

重新生成：在仓库根目录使用包含 `cadquery==2.6.1` 的 Python 运行 `source_cad/camera_bracket/v1/build_bracket.py`。源代码中的 `P` 是记录参数；修改时需同步对应建模语句。目前不是所有建模尺寸都由 `P` 自动驱动。
