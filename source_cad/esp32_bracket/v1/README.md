# 独立 ESP32 支架 v1

日期：2026-10-03。用户要求与法兰背板分离，安装在相机支架对侧的两孔。

- `esp32_bracket_v1.step`：独立支架 CAD。
- `esp32_bracket_preview.png`：支架预览。
- `esp32_installed_preview.png`：带 8 mm 隔离柱及 PCB 占位的预览。
- `parameters_and_checks.json`：联合装配检查及设计输入。

采用原 STEP 下侧两孔 x=-33.7 / -18.7、z=-65.725，孔距 15，支架安装孔 Ø3.4。双夹板中间名义 4 mm 槽夹住原两块壳体连接片。板面四孔按用户暂定 46.5 × 23.5，Ø4.0，实物匹配和尺寸误差仍未核定。支架不连接法兰件。板和接头占位比原壳体更低，最低 z=-97，需检查工作区净空。

源代码与完整装配在 [背板 v2](../../backplate/v2/README.md) 中，导出的此 STEP 是独立零件。原 CAD、相机支架和背板旧版本保留。
